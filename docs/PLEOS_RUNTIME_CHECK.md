# Pleos 실행 검증

2026-11-15 · Windows · Pleos Connect 2.1.0 / API 34 / x86_64 · RAM 4GB

## 통과한 항목

- 서명한 release APK 설치·실행, 저장 동의 및 위치·차량 권한 요청을 확인했다.
- 공식 Virtual Console의 8088 포트를 연결했다. Console에서 D 기어 반영과 SDK 기어 콜백을 확인했다.
- D 상태에서 속도 36km/h와 GPS 위치를 약 1초 간격으로 변경하고 속도 0·P로 종료했다. 위치는 에뮬레이터 입력이며 실차 도로 주행이 아니다.
- 앱은 주행을 자동 종료하고 승인 경로 289m·1개 구간을 저장했다. 원시 입력 전체가 승인 거리로 저장됐다는 뜻은 아니다.
- 노들섬 명소 수집과 재부팅 후 수집 상태 유지를 확인했다.
- 충돌로 남은 중단 기록을 복구 종료했다. 승인 거리 0m 기록은 짧은 주행으로 처리됐고 기존 완료 주행·수집은 유지됐다.
- release APK 업데이트 설치 후 완료 주행 유지와 경로 기록 화면의 수정 문구를 확인했다.
- 명소 음성 연결 후 app debug·release 각각 83개 테스트, 양쪽 APK 빌드·lint를 통과했다. 도메인 코드는 이번 루프에서 변경하지 않았다.

## 에뮬레이터 실행 방식

이 PC의 Emulator 37.2.13에서는 headless QEMU가 두 차례 0xc0000005로 종료됐다. GPU를 소프트웨어 렌더링으로 바꾸기만 해서는 해결되지 않았다. 일반 QEMU, `-gpu swiftshader -feature -Vulkan -no-snapshot -qt-hide-window` 조합에서는 같은 주행 시나리오를 완료했다. 장시간 안정성을 보장하는 결과는 아니다.

공식 Virtual Console 안내: https://document.pleos.ai/docs/connect/guide/getting-started/application-development/use-vehicle-emulator

## 음성 연결

- 기존 지역 배지·칭호에 이어 실제 GPS 명소 수집도 같은 안전 정책을 통과할 때 안내 후보로 사용한다. 시연 기록과 다른 Trip의 보상은 제외한다.
- 음성 시도 여부는 암호화 DB에 저장한다. 재실행 후 중복 시도를 막되 화면의 보상 확인 상태는 변경하지 않는다. 전체 삭제 시 시도 기록도 지운다.
- 음성 기본 OFF와 동의·D 기어·브레이크·조향·내비 신호의 최신성 검사를 유지한다. 조건이 부족하면 발화하지 않는다.

## 남은 검증

- 실제 스피커 음성 출력 및 내비 안내와 함께 실행한 안전 조건 검증. 현재 AVD는 오디오 출력 없이 실행했다.
- 조향·브레이크·방향지시등 각각의 전체 변경 시나리오.
- 실제 지역 경계 데이터와 지역 배지 수집. 반경 기반 명소 수집으로 이를 대체하지 않는다.
- 실차 실행과 장시간 주행, Pleos 네이티브 카카오 지도 실행.
