## 기준과 범위

- origin/main `92779e2`의 F-02·05·07·12·13 도메인 코드와 최신 계약을 로컬 파일로 반영했다. Git 병합 커밋·push는 만들지 않았다.
- 이번 Android 연결은 F-05 방문·배지·미확인 배지 보상에 한정한다. 고스트·칭호·차량 상태기계는 도메인 코드 수령과 Android 통합 완료를 구분한다.
- RegionCatalogLoader가 catalog/manifest.json의 버전·좌표계·실제 자료 여부·출처/라이선스·파일 SHA-256을 확인한다. regions.geojson의 문자열 코드, Polygon/MultiPolygon, hole, 좌표 순서와 badge asset을 검증한 뒤 IndexedRegionCatalog를 만든다.
- 데이터 없음과 데이터 오류를 구분해 도감에 표시하며, 어느 경우도 방문 판정을 실행하지 않는다. 실제 경계·엠블럼 파일은 아직 전달되지 않았다. 기존 legacy/landmarks.json을 행정구역 경계로 쓰지 않는다.

## 연결

- Android GPS 진단 입력의 F-03 저장 성공 후 승인 위치·실제 연결 거리·공백 여부를 ProcessRegionVisitUseCase에 전달한다. 거절 입력은 연속성을 끊는다. 새 실행은 방문 세션을 복구하면서 이전 실행과 경로를 연결하지 않는다.
- 합성 경로 재생은 실제 카탈로그의 배지 지급과 연결하지 않는다. 테스트에서만 합성 폴리곤을 주입한다.
- 기존 Room DB의 암호화 payload 테이블에 방문 snapshot·배지·방문 목록·미확인 보상을 저장한다. 방문 결과 묶음은 revision 확인 후 한 트랜잭션으로 반영한다. DB 스키마는 바뀌지 않는다.
- 보상 deduplicationKey를 보존하고, 확인 버튼을 누를 때만 acknowledgedAtMs를 저장한다. 앱 재실행으로 미확인 보상을 없애지 않는다.
- 개별 Trip 삭제·200m 미만 폐기 시 배지는 유지하고 해당 Trip 참조와 방문 목록을 정리한다. 전체 삭제는 방문 snapshot·배지·보상을 함께 삭제한다.
- 정차 도감에 미획득/획득, 방문 횟수, 가장 오래된 미확인 배지와 확인 버튼을 표시한다. 기존 차량 UX 접근 제한·ViewModel 실행 검사를 따른다.

## 남은 통합

- 실제 지역 카탈로그와 엠블럼 공급·화면 확인. 현재 도감은 데이터 준비 안내가 정상이다.
- 후속 반복 검증에서 GPS 입력의 F-03·F-05·고스트·칭호를 공통 Room 트랜잭션으로 묶었다. 현재 저장·복구 범위는 DRIVE_INTEGRATION_LOOPS.md를 따른다.
- Trip 종료 후 정차 체류를 계속 관측하는 프로덕션 입력 세션, 실제 Pleos 입력과 F-02 상태기계 연결.
- F-07 칭호·F-12/13 고스트 저장·조회는 후속 연결했다. 통합 TTS 보상 발화·배지 엠블럼·지도 마커 표시는 남아 있다.
