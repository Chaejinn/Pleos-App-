# 명소·웹 지도 통합

2026-11-15 · 기준 merge_jhmin 7b8387b

- 기존 미커밋 작업은 .local/before-hyeonmin-*에 백업하고 현민 원본은 .local/hyeonmin-verify 작업 폴더에서 먼저 테스트·빌드·lint를 통과시켰다.
- .env 로더, x86 JavaScript 지도, 네이티브 지도 명소 마커, 897개 명소 카탈로그·검색·상세·지도 이동, 명소 수집·확인을 현재 작업에 연결했다.
- 기존 지역 방문·칭호·고스트·주행 상태기계·정차 관측·복구 코드는 보존했다. 반경 기반 명소 수집과 폴리곤 기반 지역 방문은 다른 모델이며 서로 대체하지 않는다. 현재 실제 지역 경계 파일은 없다.
- 명소 방문은 F-03 승인 위치만 사용하며 실제 GPS와 REPLAY 키를 분리한다. 시연 수집·칭호·고스트 결과는 시연 표시를 유지한다.
- 현민의 시연 고스트·칭호 처리는 별도 REPLAY 저장 경로로 반영했다. 실제 GPS는 기존 공통 코디네이터가 처리한다. 도로 인덱스도 실제 GPS·REPLAY·기존 미확인 기록을 분리한다.
- 주행 삭제는 수집·칭호를 보존하고 해당 Trip 참조를 해제한다. 닫힌 고스트 checkpoint에 남은 원본 참조와 캐시는 삭제 시 함께 정리한다. 전체 삭제는 같은 DB의 수집·칭호·보상을 모두 지운다.
- README, 원격의 .bak 파일, PDF 생성 도구·제출 문서 묶음은 이번 코드 통합에 덮어쓰지 않았다. .env·로컬 키·서명 파일은 커밋 대상이 아니다.
- .env 입력 후 API 37 x86_64 에뮬레이터에서 카카오 JavaScript 지도 인증·타일·경로 표시를 확인했다. 지도 객체 준비, 명소 897개 등록과 타일 이미지 로딩을 WebView에서 확인했다. Pleos의 네이티브 지도와 차량 SDK 실행 검증은 별도로 남아 있다.
- Pleos Connect 2.1.0 API 34 전용 AVD를 설치하고 RAM 4GB 콜드 부팅을 확인했다. 서명한 release APK 설치·실행, 저장 동의·권한 요청, 차량 신호 연결, SDK의 VENDOR_GEAR_SELECTION 콜백 및 반복 조회 응답 수신까지 확인했다. 이 결과는 전체 주행 검증을 뜻하지 않는다. Virtual Console로 D→위치 이동→P, 속도·조향·브레이크·방향지시등, 실제 음성 출력 검증이 남아 있다.
