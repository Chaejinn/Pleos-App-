# 기능명세서 – 차량 기반 실시간 탐험·수집 서비스

2026-11-11

## 1. 문서 개요

이 문서는 기획서 v1.1의 네 가지 핵심 기능(주행 지도·지역 방문 기록, 뱃지·칭호, 주행 아카이브, 실시간 고스트 모드)을 개발자가 바로 구현할 수 있는 단위로 나눈 기능명세서다. 공모전 MVP(접수 마감 11/15, 2차 PT 12/3~4) 범위를 기준으로 한다.

- 대상 플랫폼: Pleos Connect (Android Automotive), Kotlin, minSdk 28
- 기준 문서: 차량 기반 실시간 탐험·수집 서비스 기획서 v1.1
- 범위 밖: 소셜·랭킹, 레벨·경험치, 게임 재화, 지도 암전(Fog of War), 여행 추천, 속도 경쟁

**용어 정의**

| 용어 | 정의 |
| --- | --- |
| 주행(Trip) | 기어 D 진입부터 P 진입까지의 한 번의 운행 |
| 트랙 포인트 | 주행 중 일정 간격으로 저장하는 위치·시각·차량 상태 한 건 |
| 유효 방문 | 지역 뱃지 지급 조건(체류 거리·시간)을 만족한 방문 |
| 지역 뱃지 | 시·군·구 단위 방문 수집품 |
| 대학 뱃지 | 대학 주변 지정 방문 구역 수집품 (선택 기능) |
| 칭호 | 특별한 주행 조건 달성 보상 |
| 고스트 구간 | 과거 주행과 같은 도로·같은 진행 방향으로 일정 길이 이상 겹치는 구간 |
| 주행 중 / 정차 중 | 기어가 P가 아니고 속도 > 0 / 기어 P 또는 주차 브레이크 체결 |

## 2. 주행 상태별 화면·알림 정책

실시간 판정은 항상 돌리고, 화면에 무엇을 보여줄지는 주행 상태로 나눈다. 주행 중에 얻은 뱃지·칭호·고스트 결과는 큐에 쌓아 두었다가 정차 시 한꺼번에 보여준다.

| 항목 | 주행 중 | 정차 중 (P단·주차 브레이크) |
| --- | --- | --- |
| 위치 수신·경로 기록 | 동작 | 일시 중지 (정차 지점 1건만 기록) |
| 뱃지·칭호 판정 | 동작 | 동작 |
| 고스트 구간 판정·비교 계산 | 동작 | 해당 없음 |
| 지도 화면 | 현재 위치·주행 경로선만, 터치 조작 최소화 | 전체 표시 (뱃지 마커, 고스트 경로 겹쳐 보기) |
| 뱃지 획득 알림 | 아이콘 배지 숫자만 (애니메이션 없음) | 획득 카드 팝업 |
| 음성 알림 (TTS) | 사용자 설정 ON일 때만, 획득 1회 1문장, 최소 간격 60초 | 사용 안 함 |
| 뱃지 도감·주행 기록 화면 | 진입 불가 (정차 후 이용 안내) | 이용 가능 |
- 주행 상태는 Vehicle SDK의 기어 상태와 Brake(주차 브레이크)로 판단하고, 얻을 수 없으면 속도 0이 10초 이상 이어지는 것으로 대신한다.
- 주행 중 허용 범위는 Pleos 주행 안전 설계 가이드와 앱 카테고리 정책을 따르며, 가이드가 더 엄격하면 가이드를 우선한다.

## 3. 화면 목록

화면은 세 개로 제한하고, 하단 탭으로 전환한다. 앱 실행 시 기본 화면은 탐험 지도다.

| ID | 화면 | 핵심 요소 | 주행 중 | 관련 기능 |
| --- | --- | --- | --- | --- |
| S-01 | 탐험 지도 | 현재 위치, 누적 주행 경로선, 획득 지역 뱃지 마커, 미확인 획득 배지 | 간소 모드 | F-01, F-02, F-04, F-11 |
| S-02 | 뱃지 도감 | 시·도별 지역 뱃지 그리드(미획득은 어둡게), 대학 뱃지 탭, 칭호 목록, 수집 개수 | 진입 불가 | F-05, F-06, F-07, F-08 |
| S-03 | 주행 기록 | 주행 목록(최신순), 주행 상세(경로, 거리, 방문 지역, 획득 보상, 주행 특성), 고스트 비교 상세 | 진입 불가 | F-09, F-12, F-13 |

**팝업·상세 화면**

- P-01 획득 카드: 정차 시 주행 중 쌓인 뱃지·칭호를 순서대로 표시 (F-10)
- P-02 뱃지 상세: 뱃지 일러스트, 최초 획득일, 획득 당시 주행 기록 바로가기 (지도 마커·도감에서 진입)
- P-03 위치 권한·기록 동의: 최초 실행 시 1회 (F-14)
- P-04 설정: 음성 알림 ON/OFF, 기록 전체 삭제 (F-14)

## 5. 기능 상세 명세

수치는 모두 초기값이며, 에뮬레이터 테스트 후 동현이 조정해 이 문서에 반영한다.

### F-01 실시간 위치 수신

- 입력: FusedLocation 위치 업데이트 (위도, 경도, 속도, 진행 방향, 정확도, 시각)
- 처리: 1초 간격으로 요청하고, 정확도 50m를 넘는 위치는 버린다.
- 출력: 검증된 위치를 F-03, F-05, F-06, F-12에 전달
- 예외: 위치 권한이 없으면 P-03을 띄우고 기록을 시작하지 않는다. 터널 등으로 10초 이상 수신이 끊기면 끊긴 구간으로 표시하고 다시 이어 받는다.

### F-02 주행 시작·종료 감지

- 시작: 기어가 D 또는 R로 바뀌면 새 Trip을 만든다. 기어 정보를 못 얻으면 속도 5km/h 이상이 30초 이어질 때 시작한다.
- 종료: 기어 P 진입, 또는 속도 0이 5분 이상 이어지면 Trip을 닫는다.
- 출력: Trip 시작·종료 이벤트, 주행 중/정차 중 상태 (2장 정책의 기준)
- 예외: 주행 거리 200m 미만 Trip은 저장하지 않는다 (주차장 이동 등).

### F-03 주행 경로 기록·보정

- 처리: 20m 이동 또는 5초마다 TrackPoint를 저장한다. 직전 지점과 비교해 200km/h를 넘는 도약은 튐 값으로 보고 버린다.
- 저장: Trip 종료 시 허용 오차 5m로 경로를 단순화해 지도 표시용으로 보관하고, 원본은 고스트 비교용으로 유지한다.
- 생성: 지나간 도로를 약 100m 격자 단위 ExploredRoad로 기록하고, 처음 기록된 격자인지 표시한다 (F-07 신규 도로 거리에 사용).

### F-04 지도 주행 경로 표시

- 일반 지도 배경을 유지하고, 과거 경로는 연한 선, 오늘 주행은 진한 선으로 그린다.
- 미방문 지역 암전, 방문 지역 배경색 변경은 하지 않는다.
- 주행 중에는 현재 위치를 화면 중앙에 고정하고 확대·축소 조작만 허용한다.

### F-05 지역 방문 판정·지역 뱃지 지급

- 데이터: 전국 시·군·구 경계 데이터(약 250개)를 앱에 내장한다. 출처 후보는 통계청 SGIS 또는 공공데이터포털이며 현민이 확정한다.
- 처리: 위치가 어느 시·군·구 안에 있는지 판정한다 (경계 상자로 후보를 좁힌 뒤 폴리곤 포함 검사).
- 유효 방문 기준: 해당 지역 안에서 주행 거리 1km 이상 또는 체류 3분 이상. 경계를 스치듯 지나간 경우는 제외한다.
- 출력: 최초 유효 방문이면 RegionBadge 생성 후 F-10 큐에 넣는다. 이미 있으면 방문 횟수만 1 올린다.

### F-06 대학 뱃지 판정 (선택)

- 데이터: 대학별 방문 구역(차량 접근 가능한 주변 도로 기준 반경 300m). MVP는 10개 대학으로 시작한다.
- 처리: FusedLocation 구역 진입 알림으로 감지하고, 구역 안 주행 300m 또는 체류 1분 이상이면 지급한다.
- 제약: 공식 교표·마스코트는 쓰지 않고 자체 일러스트만 쓴다.

### F-07 칭호 조건 판정

| 칭호 | 판정 기준 (초기값) | 판정 시점 |
| --- | --- | --- |
| 동해에서 서해로 | 같은 날(00~24시)에 동해안 지정 지점 1곳과 서해안 지정 지점 1곳의 반경 2km 안에 진입 | 지점 진입 시 |
| 전국 탐험가 | 서로 다른 시·군·구 지역 뱃지 30개 획득 | 뱃지 지급 시 |
| 새로운 길의 발견자 | 처음 기록된 도로(ExploredRoad) 누적 100km | Trip 종료 시 |
| 다시 찾은 길 | 마지막 통과에서 30일 이상 지난 고스트 구간을 5km 이상 재주행 | 고스트 구간 종료 시 |
- 저장: 달성 조건, 획득 일시, 관련 Trip ID
- 안전: 소요 시간·속도를 조건에 넣지 않는다. 동해에서 서해로는 하루 단위라 무리한 운행을 부추길 수 있어 2차 PT 전에 기준을 다시 검토한다.

### F-08 뱃지 도감

- 시·도별로 묶은 지역 뱃지 그리드, 대학 뱃지 탭, 칭호 목록을 보여준다.
- 미획득 뱃지는 어둡게, 획득 뱃지는 원래 일러스트로 표시한다 (이 효과는 도감에만).
- 상단에 획득 수 / 전체 수를 표시하고, 뱃지를 누르면 P-02로 간다.
- 일러스트: MVP는 공통 엠블럼 + 지역명으로 전국을 채우고, 시연 경로에 있는 지역만 상징물 일러스트를 넣는다.

### F-09 주행 아카이브

- 목록: 최신순, 각 항목에 날짜, 거리, 방문 지역 수, 획득 보상 수
- 상세: 경로 지도, 시작·종료 시각, 거리, 방문 지역, 획득 뱃지·칭호, 주행 특성(F-15), 고스트 비교 결과(F-13)
- 주행별 삭제를 제공한다. 삭제해도 이미 받은 뱃지·칭호는 남는다.

### F-10 주행 중 보상 보류·정차 시 표시

- 주행 중 발생한 뱃지·칭호·고스트 결과는 보상 큐에 쌓는다. 지도 아이콘에는 개수 배지만 표시한다.
- 정차 상태가 되면 P-01 획득 카드로 큐를 비운다.
- 음성(설정 ON일 때만): 획득 1건에 한 문장 (예: "수원시 뱃지를 받았어요"), 최소 간격 60초.

### F-11 지도 위 뱃지 마커

- 획득한 지역 뱃지를 시·군·구 대표 좌표에 마커로 표시한다.
- 전국이 보이는 줌에서는 시·도 단위로 묶어 개수를 표시한다.
- 마커를 누르면 P-02 (정차 중에만).

### F-12 고스트 구간 인식

- 입력: 현재 위치·진행 방향, 과거 TrackPoint (약 100m 격자 키로 주변만 조회)
- 시작 조건: 현재 지점 반경 30m 안에 과거 지점이 있고 진행 방향 차이가 45° 이내인 상태가 연속 500m 이어지면 고스트 구간으로 판정
- 종료 조건: 일치하지 않는 상태가 200m 이어지면 구간 종료
- 비교 대상: 같은 구간을 지난 주행이 여럿이면 가장 최근 주행과 비교하고, 최초 통과일은 가장 오래된 주행에서 가져온다.
- 출발지·목적지가 달라도 같은 도로를 지나면 비교한다.

### F-13 고스트 비교

| 비교 항목 | 내용 | 주행 중 | 정차 중 |
| --- | --- | --- | --- |
| 과거 방문 정보 | 이 도로를 처음 지난 날짜 | 음성 1문장 (설정 ON) | 표시 |
| 경로 비교 | 일치 구간 거리, 겹친 경로 | 계산만 | 두 경로 겹쳐 보기 |
| 새로운 발견 | 고스트 구간을 벗어나 처음 지난 도로 거리 | 계산만 | 표시 |
| 주행 스타일 | 같은 구간의 급제동·급조향 횟수, 방향지시등 사용률, 평균 연비·전비 변화 | 계산만 | 표시 |
- 속도, 소요 시간, 도착 순서는 비교하지 않는다.
- 선택 기능: 정차 중 고스트 경로 리플레이 (두 주행을 같은 위치 기준으로 나란히 재생)

### F-14 권한·동의·설정·기록 삭제

- 최초 실행: 위치 권한 요청, 위치 기록 저장 동의 (동의 전에는 아무것도 기록하지 않음)
- 설정: 음성 알림 ON/OFF (기본 OFF), 기록 전체 삭제 (뱃지·칭호 포함, 확인 1회)

### F-15 주행 특성 수집

| 지표 | 산출 기준 (초기값) | 데이터 |
| --- | --- | --- |
| 급제동 | 감속도 3.0m/s² 이상 | 속도 변화, Brake 페달 |
| 급조향 | 시속 20km 이상에서 핸들 각속도 180°/s 이상 | SteeringWheel |
| 방향지시등 사용률 | 핸들 90° 이상 회전 중 직전 5초 안에 방향지시등을 켠 비율 | SteeringWheel, TurnSignal |
| 평균 효율 | 구간 평균 연비(km/L) 또는 전비(km/kWh) | Fuel / EvBattery |
| 주행 거리 | 차량 적산거리 차이 (GPS 거리와 교차 확인) | Odometer |
- 1km 구간 단위로 집계해 TrackPoint와 같은 위치에 연결한다. F-13 주행 스타일 비교의 입력이다.
- 차량 데이터를 얻지 못하면 해당 지표는 비워 두고, 위치 기반 기능은 그대로 동작한다.

## 6. 데이터 모델

모든 데이터는 Room 로컬 DB에 저장하며 서버로 보내지 않는다. 시각은 epoch 밀리초, 거리는 m 단위다.

| 엔티티 | 주요 필드 | 관계 |
| --- | --- | --- |
| Trip | id, startedAt, endedAt, distanceM, odometerStartKm, odometerEndKm, simplifiedPath | TrackPoint·DrivingMetrics 1:N |
| TrackPoint | id, tripId, time, lat, lon, speedMps, bearingDeg, accuracyM, gridKey | Trip N:1 |
| ExploredRoad | gridKey(PK), firstTripId, firstVisitedAt, lastVisitedAt, visitCount | 격자별 1건 |
| RegionBadge | regionCode(PK, 행정구역 코드), type(REGION/UNIVERSITY), firstTripId, acquiredAt, visitCount | Trip 참조 |
| AchievementTitle | titleId(PK), conditionText, acquiredAt, tripId | Trip 참조 |
| DrivingMetrics | id, tripId, segmentIndex, startPointId, harshBrakes, harshSteers, turnSignalRate, avgEfficiency | Trip N:1 |
| GhostResult | id, tripId, pastTripId, matchedDistanceM, firstPassedAt, newRoadM, metricsDiff | Trip 2건 참조 |
- 앱 내장 정적 데이터(읽기 전용): 시·군·구 경계와 대표 좌표, 대학 방문 구역, 칭호 지정 지점(동해안·서해안), 뱃지 일러스트
- GhostResult는 기획서의 데이터 구조에 없던 항목으로, F-13 결과를 주행 기록 화면에서 다시 보여주기 위해 추가했다.
- 보관 기간: 원본 TrackPoint는 최근 180일, 단순화 경로·뱃지·칭호·ExploredRoad는 삭제 요청 전까지

## 7. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 주행 안전 | 주행 중 화면은 2장 정책을 따른다. 애니메이션·텍스트 입력·스크롤 목록 없음. 속도·소요 시간 경쟁 요소 없음 |
| 차량 권한 | Vehicle SDK는 조회 권한만 사용하고 차량 제어 권한은 쓰지 않는다 |
| 성능 | 위치 1건 처리(지역 판정 + 고스트 판정) 50ms 이내. 지도 경로 표시는 단순화 경로 사용 |
| 백그라운드 | 다른 앱(내비 등)이 앞에 있어도 포그라운드 서비스로 기록을 이어간다. Pleos 환경에서 동작 여부를 먼저 검증한다 |
| 오프라인 | 모든 판정은 기기 안에서 수행한다. 지도 타일을 못 받아도 기록·판정은 동작한다 |
| 개인정보 | 위치 기록 동의 후에만 저장, 서버 전송 없음, 주행별·전체 삭제 제공 |
| 저장 용량 | 1시간 주행당 약 720건(5초 간격) 기준, 180일 보관 후 원본 자동 정리 |
| 화면 | 차량 가로형 대화면 기준, 터치 대상 최소 76dp, 글자 최소 24sp |
| 테스트 | 판정 로직(F-03, F-05, F-07, F-12, F-15)은 안드로이드 없이 돌리는 단위 테스트로 검증한다 |

## 8. MVP 범위·일정·미결 사항
