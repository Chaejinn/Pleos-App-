## 종료 문제와 제한
첫 에뮬레이터 부팅에서 System UI 응답 없음이 발생했고 시스템이 WebView 프로세스를 종료한 기록이 있었다. 이를 사용자 보고 종료 문제의 확정 원인으로 단정하지 않는다.

WebView 렌더러 종료 콜백에서 앱 종료를 방지하도록 처리하고, 종료된 뷰 제거·폐기·재연결을 구현했다. 아카이브에서 여러 비교 지도를 동시에 생성하지 않고 선택한 비교 지도 하나만 표시하도록 변경했다. 렌더러 강제 종료 주입 시험은 수행하지 않았다.

실제 차량 위치·기어·속도·UX 제한, 네트워크 장애 복귀, 장시간 운행·50ms 성능, 180일 정리, 원본 명세의 미연결 기능은 별도 검증·구현 대상이다. 사용자 데이터 전체 삭제 테스트는 수행하지 않았다.
